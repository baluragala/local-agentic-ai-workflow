03 · VALIDATION & EXECUTION

Nothing runs until the app checks it

1

Does the tool exist?

Small models invent names like issue_refund.

2

Are the arguments valid?

Required present, no extras, enums respected. "149.00" as a string is coerced.

3

Business preconditions

Refund only after an eligible check. Ticket only with the exact calculated amount.

errors = validate_tool_call(name, args, state)
result = {"error": ...} if errors else execute_tool(name, args)  # rejected = never executed
state.messages.append({"role": "tool", "content": json.dumps(result)})  # model can self-correct
Check 3 is the key idea: workflow order that the business requires is enforced in code, not left to the prompt. execute_tool also catches exceptions so a crashing tool never crashes the agent.
