01 · WHY AGENTIC?

The path depends on what the tools return

order missing

Stop, tell the customer

get_order returns “not found”.

outside window

Decline with reason

No refund calculation at all.

status question

One lookup is enough

Then answer.

no order ID

Ask, don’t guess

Call no tools.

Use an agent when a task needs dynamic decisions, conditional tool use, iteration and adaptation to intermediate results. If the path is always the same, a plain program is cheaper and safer.

Ask the room: could we write this as a fixed if/else script? Partly, yes, and that is the point. The agent earns its place when inputs are free text and the path branches on intermediate results. Do not oversell agents.
