while state.step < max_steps:
    state.step += 1
    msg, calls = call_llm(state.messages, tools=TOOL_SCHEMAS)      # 🧠 model proposes
    if not calls:
        gap = completion_gap(state)                              # 📦 eligible but no ticket?
        if gap and progressed: nudge(gap); continue
        state.final_answer = msg["content"]; break
    for c in calls:
        errors = validate_tool_call(c.name, c.args, state)            # 🛡️ app checks
        result = error if errors else execute_tool(c.name, c.args) # 🔧 app executes
        state.messages.append(tool_message(result))                  # result → state

state.status = derive_status(state)   # from TOOL RESULTS, not the model’s words
The nudge names the exact next call and repeats only while the model makes progress (max 3), so a model that ignores it cannot loop.
