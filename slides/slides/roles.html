01 · WHO DOES WHAT

The model proposes.
The application disposes.

MODEL

Generates text, plans and tool-call requests. Never runs code.

ORCHESTRATOR

Validates and executes tools, enforces rules, keeps state, decides when to stop.

ENVIRONMENT

Python process + Ollama server on localhost:11434, on Colab or a laptop.

This is the single sentence learners should remember. Instructions (system prompts) steer the model; tools do the real work; state is the memory of a run. We return to this slide in the recap.
