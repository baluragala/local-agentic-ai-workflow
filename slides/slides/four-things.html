Four different things happen in one run

🧠 LLM

Response generation

Fluent text for the customer: the final answer.

🧠 LLM

Planning / next action

Plan JSON and each tool request: the model choosing.

🔧 TOOL

Tool execution

Deterministic Python, run by the application.

📦 🛡️ 📋

Workflow / state

Validating, recording, nudging, stopping.

Only the dark half involves the model. The light half is ordinary software, which is why it is reliable, testable and debuggable.
