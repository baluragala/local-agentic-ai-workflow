03 · WORKFLOW STATE

One object remembers the whole run

@dataclass
class AgentState:
    request: str
    plan: dict | None
    messages: list   # conversation
    tool_calls: list # name, args, result
    trace: list      # every event + layer
    status: str
    final_answer: str | None
    step: int
LayerLogged when …
🧠 LLMmodel generated a plan, tool request or answer
📋 PLANplan accepted, hallucinated ID caught
🛡️ VALIDATEapp accepted or rejected a request
🔧 TOOLapp executed a tool
📦 STATEstart, nudge, termination

Tagging every event with its layer means we can always answer: who did what, and where did it go wrong?

The trace is the debugging superpower for the rest of the session. Show trace_table(state) as a DataFrame after the first full run.
