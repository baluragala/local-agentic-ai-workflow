↺ Steps 4–6 loop until done. A 1.5B model on a free GPU created correct refund tickets: the workflow around the model is what made it reliable.

Walk one request through all eight steps: "Order ORD-1002, headphones arrived damaged, please refund me." Dark cards are the only places the model acts; everything else is our code. Five takeaways: (1) an agent is a loop, not a prompt; (2) tools are ordinary code, so test them first; (3) business rules belong in validators, not prompts; (4) fluent is not correct: trust tool results, not the model's words; (5) evaluate response quality, workflow execution and business outcome across many test cases. Two real stories from building this course: the order ID disappeared because the schema made it optional, so the small model skipped it (fix: required fields, regex extraction for fixed-format IDs); and the agent gave up after get_order because only one nudge was allowed (fix: specific nudges, capped, only while the model makes progress). Debugging habit: reproduce, read the trace by layer, find the first wrong event, fix, add a test case.
