Tools are ordinary deterministic Python over a mock database. No AI inside them, so we can test them before any model is involved.

Keep tools few and simple on purpose. Point out the dependency chain: refund needs eligibility, ticket needs the refund amount. That dependency is what makes the task multi-step and conditional.
